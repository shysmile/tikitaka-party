# 티키타카 파티 (휴대폰용)

회의실 TV(사업관리포탈 티키타카 → 회의실 파티 → 진행자 화면)와 같은 방 코드 · 라운드를 넣으면 같은 문제가 나오는 협동 미니게임 6종입니다(6번째 점심 메뉴 고르기 — 휴대폰으로 취향을 올리면 TV 가 걸러 룰렛, 11-23).
문제는 방 코드로 양쪽에서 똑같이 만들어 내므로 서버 · 데이터베이스가 없어도 됩니다. 사내 정보는 들어 있지 않습니다.

- index.html = tikitaka_party.html (같은 파일)
- 주소 뒤에 ?r=방코드&n=라운드 를 붙이면 바로 그 방으로 들어갑니다(진행자 화면 QR 이 그렇게 만듭니다).

## 점수 중계 (선택)

컬러 헌터 [점수판에 올리기] · 릴레이 타이머 [기록 올리기] · 텔레파시 [답 올리기] · 점심 [취향 올리기] 를 누르면 닉네임과 점수(텔레파시는 24자 답)만 아래 중계 서버로 보내고, 진행자 화면이 3초마다 받아 옵니다(타이머는 주자 칸에 차례대로, 텔레파시는 "공개!" 때 같은 답끼리 묶어 순위로).

- 주소: https://tikitaka-relay.shysmile.workers.dev (Cloudflare Workers 무료, 소스는 사내 Biz\tiki\relay)
- 받는 것: 방 코드 · 라운드 · 게임 · 닉네임(12자) · 점수 · 텔레파시 답(24자) · 점심 취향(0~4444 숫자 하나). 한 판 60명, 12시간 뒤 저절로 지움
- 다른 중계를 쓰려면 주소 뒤에 &relay=https://... 를 붙입니다
- 중계에 닿지 않으면 예전처럼 점수를 불러 주고 진행자가 손으로 넣습니다
